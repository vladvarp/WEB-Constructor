# Память проекта WEB-Constructor

## Назначение
Windows-приложение для визуального создания сайтов, редактирования кода и экспорта независимых HTML/CSS/JS-проектов.

## Требования
- Python backend; веб-интерфейс в собственном окне приложения.
- Запуск через launch.vbs без видимой консоли.
- CSS и JavaScript разделены на понятные файлы.
- Расширение через модульную систему.
- ИИ читает правила и память перед изменениями.
- Несвязанные части программы не затрагиваются.
- Встроенный подробный FAQ с иллюстрациями.
- Готовые сайты не зависят от Python или конструктора.

## Архитектурные решения
- Собственная версионируемая модель проекта.
- Редактор отделён от модели и экспортёра.
- GrapesJS может быть адаптируемым движком, но не форматом хранения.
- Модули общаются через публичные контракты.
- Динамическое исполнение модулей требует модели безопасности.

## Текущее состояние
- Основа 0.1.0.
- FastAPI раздаёт UI и локальный API; pywebview отображает его в отдельном окне.
- Реестр обнаруживает и проверяет JSON-манифесты, но не загружает код.
- Управление проектами, редактор и экспорт ещё не реализованы.

## Обновление памяти
После архитектурно значимых изменений обновлять этот файл и связанные документы. Не записывать планы как реализованные функции.
