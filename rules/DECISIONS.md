# Архитектурные решения

## ADR-001. Собственная модель проекта
**Статус:** принято. Данные сайта хранятся в собственной версионируемой модели, а не в формате стороннего редактора.

## ADR-002. Разделение редактора и экспортёра
**Статус:** принято. Экспортёр преобразует модель проекта в независимые HTML/CSS/JS и не зависит от UI.

## ADR-003. Безопасная система модулей
**Статус:** принято. Первая версия реестра только проверяет манифесты. Исполнение кода отложено до проектирования разрешений и изоляции.

## ADR-004. Локальный backend
**Статус:** принято. FastAPI слушает только 127.0.0.1; интерфейс и API обслуживаются одним локальным сервером.

## ADR-005. Пользовательское хранилище проектов
**Статус:** принято. Проекты размещаются в пользовательском каталоге данных, отдельно от каталога установки приложения. Каждый проект имеет UUID-каталог и собственные project.json, assets/ и exports/.

## ADR-006. Версионируемая Project Model
**Статус:** принято. Канонический формат проекта — JSON с schema_version. Модель не зависит от DOM и визуального редактора; переходы формата выполняются последовательными миграциями.
