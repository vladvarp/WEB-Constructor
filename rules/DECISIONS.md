# Архитектурные решения

## ADR-001. Собственная модель проекта
**Статус:** принято. Данные сайта хранятся в собственной версионируемой модели, а не в формате стороннего редактора.

## ADR-002. Разделение редактора и экспортёра
**Статус:** принято. Экспортёр преобразует модель проекта в независимые HTML/CSS/JS и не зависит от UI.

## ADR-003. Безопасная система модулей
**Статус:** принято. Первая версия реестра только проверяет манифесты. Исполнение кода отложено до проектирования разрешений и изоляции.

## ADR-004. Локальный backend
**Статус:** принято. FastAPI слушает только 127.0.0.1; интерфейс и API обслуживаются одним локальным сервером.

## ADR-005. Пользовательское хранилище проектов
**Статус:** принято. Проекты размещаются в пользовательском каталоге данных, отдельно от каталога установки приложения. Каждый проект имеет UUID-каталог и собственные project.json, assets/ и exports/.

## ADR-006. Версионируемая Project Model
**Статус:** принято. Канонический формат проекта — JSON с schema_version. Модель не зависит от DOM и визуального редактора; переходы формата выполняются последовательными миграциями.

## ADR-007. Управление страницами через ProjectStore
**Статус:** принято. CRUD страниц, назначение главной и сортировка выполняются сервисом хранилища с атомарным сохранением Project Model. У проекта всегда остаётся одна главная страница и минимум одна страница; при удалении главной автоматически назначается первая оставшаяся.

## ADR-008. Навигация как часть Project Model
**Статус:** принято. Меню хранятся в модели проекта как дерево независимых от DOM пунктов. Внутренние ссылки используют UUID страниц; внешние URL допускают только абсолютные HTTP/HTTPS. Удаление страницы каскадно удаляет ведущие на неё пункты и их дочерние поддеревья. Отрисовка меню на сайте относится к будущему Export Engine.

## ADR-009. Визуальное редактирование поверх Project Model
**Статус:** принято. Холст визуально отображает независимое дерево ContentNode. Выбор и изменение элемента работают через его id и props; DOM не является форматом хранения. Первый этап включает демонстрационную стартовую страницу, базовые текстовые элементы, инспектор свойств, режимы ширины и историю Undo/Redo.
