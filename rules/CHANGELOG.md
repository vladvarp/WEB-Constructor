# История изменений

## 0.4.0 — Navigation system
- Project Model обновлена до schema v2 с миграцией v1 → v2.
- Добавлены именованные меню с размещением и древовидными пунктами.
- Реализованы внутренние ссылки по UUID страниц и безопасные внешние HTTP/HTTPS-ссылки.
- Добавлены API создания, изменения и удаления меню.
- Добавлен интерфейс управления меню, пунктами и вложенностью.
- При удалении страницы автоматически очищаются связанные пункты навигации.
- Добавлены тесты модели, хранилища и API.

## 0.3.0 — Page management
- Добавлено создание, переименование и удаление страниц.
- Добавлено изменение slug с проверкой формата и уникальности.
- Добавлено назначение главной страницы.
- При удалении главной автоматически назначается первая оставшаяся страница.
- Добавлено изменение порядка страниц.
- Добавлены отдельные API-маршруты и тесты управления страницами.
- Обновлён интерфейс списка страниц и справка.

## 0.2.0 — Project management foundation
- Добавлено пользовательское хранилище проектов.
- Реализованы создание, список, открытие, сохранение основных настроек и удаление проектов.
- Добавлена Project Model schema v1 с метаданными, настройками сайта, страницами и ресурсами.
- Добавлена миграция начального неверсированного формата и проверка версии схемы.
- Добавлена атомарная запись project.json.
- Добавлен интерфейс списка проектов, карточек и настроек проекта.
- Добавлены тесты хранилища, миграций и API.

## 0.1.0 — Application foundation
- Создана основа приложения.
- Добавлены FastAPI, Uvicorn и pywebview.
- Добавлен скрытый запуск через pythonw.exe и launch.vbs.
- Добавлены стартовый интерфейс и API проверки состояния.
- Добавлен реестр манифестов модулей без исполнения кода.
- Добавлены правила ИИ, память и архитектурная документация.
