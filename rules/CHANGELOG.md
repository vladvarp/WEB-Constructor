# История изменений

## 0.6.0 — Page structure editing
- Структура страницы редактируется через id узлов ContentNode: панель слоёв, перенос, вложение, порядок, дублирование и удаление меняют дерево, а не DOM.
- Секция добавляется в корень страницы. Заголовок, текст и кнопка вкладываются в секцию.
- Перетаскивание на холсте меняет порядок соседей и вкладывает элемент в секцию.
- Undo/Redo возвращают снимки дерева; выбранный id сохраняется, если узел остаётся в снимке.
- Повторный id узла внутри страницы отклоняется при чтении и сохранении. Версия схемы остаётся v2.

## 0.5.0 — Visual editor foundation
- Новые проекты получают демонстрационную главную страницу с редактируемой структурой ContentNode.
- Добавлен визуальный холст с выбором секций и элементов и панелью свойств.
- Добавлено создание заголовков, текстовых блоков и кнопок.
- Добавлены режимы предпросмотра Desktop, Tablet и Mobile, Undo/Redo и сохранение страницы.
- Добавлены тесты стартового содержимого проекта.

## 0.4.0 — Navigation system
- Project Model обновлена до schema v2 с миграцией v1 → v2.
- Добавлены именованные меню с размещением и древовидными пунктами.
- Реализованы внутренние ссылки по UUID страниц и безопасные внешние HTTP/HTTPS-ссылки.
- Добавлены API создания, изменения и удаления меню.
- Добавлен интерфейс управления меню, пунктами и вложенностью.
- При удалении страницы автоматически очищаются связанные пункты навигации.
- Добавлены тесты модели, хранилища и API.

## 0.3.0 — Page management

- Добавлено изменение порядка страниц.
- Добавлены отдельные API-маршруты и тесты управления страницами.
- Обновлён интерфейс списка страниц и справка.
