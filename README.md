# WEB-Constructor

Модульное Windows-приложение для визуального создания веб-сайтов.

## Статус 0.1.0
Создаётся фундамент: Python backend, собственное окно, скрытый запуск, базовый интерфейс, модульная основа и документация. Визуальный редактор и экспорт сайтов пока не реализованы.

## Требования
- Windows 10/11
- Python 3.11+
- Microsoft Edge WebView2 Runtime

## Установка и запуск
1. `py -3 -m venv .venv`
2. `.venv\\Scripts\\python.exe -m pip install -r requirements.txt`
3. Запустить `launch.vbs`.

Скрипт запускает приложение без консольного окна. Используется Python из `.venv`, а если виртуальное окружение отсутствует — первый найденный `pythonw.exe` из системного `PATH`. Одновременно может работать только один экземпляр приложения: повторный запуск будет пропущен.

Если запуск завершается ошибкой, приложение показывает сообщение, а подробности записывает в `logs/application.log`. Журнал создаётся до импорта backend и библиотек интерфейса, поэтому в нём фиксируются и ранние ошибки запуска.

Для диагностики из терминала: `py -3 main.py`.

## Принципы
- Собственная версионируемая модель проекта, независимая от GrapesJS.
- Редактор, модель проекта и экспортёр — отдельные подсистемы.
- Модули взаимодействуют через публичные контракты.
- Экспортированный сайт не зависит от Python и конструктора.
- Новые функции не должны менять несвязанные части.
