# WEB-Constructor

Модульное Windows-приложение для визуального создания веб-сайтов.

## Статус 0.2.0
Реализованы основа приложения и управление проектами: создание, список, открытие, сохранение основных настроек и удаление. Визуальный редактор, полноценное редактирование страниц и экспорт пока не реализованы.

## Требования
- Windows 10/11
- Python 3.11+
- Microsoft Edge WebView2 Runtime

## Установка и запуск
1. Установить Python 3.11 или новее.
2. Запустить `launch.vbs`.

При первом запуске приложение автоматически создаёт локальное окружение `.venv`, устанавливает зависимости из `requirements.txt` и перезапускается через Python из этого окружения. При последующих запусках pip не запускается повторно, пока файл зависимостей не изменился и необходимые модули доступны.

## Проекты
Проекты хранятся отдельно от файлов приложения:
- Windows: `%LOCALAPPDATA%\WEB-Constructor\projects`
- Другие системы: `$XDG_DATA_HOME/WEB-Constructor/projects` или `~/.local/share/WEB-Constructor/projects`

Каждый проект находится в отдельной папке с UUID и содержит:
- `project.json` — версионируемая модель сайта;
- `assets/` — ресурсы проекта;
- `exports/` — будущие сборки сайта.

Текущая версия модели — schema v1. Она содержит метаданные проекта, настройки сайта, страницы и список ресурсов. Модель не зависит от DOM или стороннего визуального редактора.

При ошибке запуска подробности записываются в `logs/application.log`. Для диагностики из терминала: `py -3 main.py`.

## Принципы
- Собственная версионируемая модель проекта, независимая от GrapesJS.
- Редактор, модель проекта и экспортёр — отдельные подсистемы.
- Модули взаимодействуют через публичные контракты.
- Экспортированный сайт не зависит от Python и конструктора.
- Новые функции не должны менять несвязанные части.
