# WEB-Constructor

Модульное Windows-приложение для визуального создания веб-сайтов.

## Статус 0.1.0
Создаётся фундамент: Python backend, собственное окно, скрытый запуск, базовый интерфейс, модульная основа и документация. Визуальный редактор и экспорт сайтов пока не реализованы.

## Требования
- Windows 10/11
- Python 3.11+
- Microsoft Edge WebView2 Runtime

## Установка и запуск
1. Установить Python 3.11 или новее.
2. Запустить `launch.vbs`.

При первом запуске приложение автоматически создаёт локальное окружение `.venv`, устанавливает зависимости из `requirements.txt` и перезапускается через Python из этого окружения. При последующих запусках проверка не запускает pip повторно, пока файл зависимостей не изменился и необходимые модули доступны.

Скрипт запускает приложение без консольного окна. Если запуск завершается ошибкой, приложение показывает сообщение, а подробности записывает в `logs/application.log`.

Для диагностики из терминала: `py -3 main.py`.

## Принципы
- Собственная версионируемая модель проекта, независимая от GrapesJS.
- Редактор, модель проекта и экспортёр — отдельные подсистемы.
- Модули взаимодействуют через публичные контракты.
- Экспортированный сайт не зависит от Python и конструктора.
- Новые функции не должны менять несвязанные части.
