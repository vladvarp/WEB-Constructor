# Справка WEB-Constructor

FAQ будет встроен в приложение и доступен офлайн. Предусмотрены категории, поиск, навигация назад/вперёд, иллюстрации, GIF-инструкции, примеры кода и перекрёстные ссылки.

Статьи о ещё не реализованных функциях не публикуются как готовые инструкции.

## Реализованные разделы
- Создание проекта: кнопка «Новый проект», название и автоматическое создание главной страницы.
- Список проектов: открытие проекта из карточки.
- Настройки проекта: название проекта, название сайта, описание и язык; сохранение изменений.
- Удаление проекта: подтверждение перед удалением.
- Страницы: создание, изменение названия и URL, назначение главной, удаление и изменение порядка.
- Правила страниц: уникальные URL; нельзя удалить последнюю страницу; при удалении главной автоматически выбирается первая оставшаяся.
- Меню: создание нескольких меню, выбор размещения, добавление внутренних и внешних ссылок, вложенные пункты, изменение порядка, переименование и удаление.
- Навигация: внутренние ссылки привязаны к UUID страниц; при удалении страницы связанные пункты меню удаляются автоматически.
- Хранение: пользовательская папка данных, структура project.json/assets/exports; модель проекта schema v2.
