# Архитектура

Основные принципы находятся в [rules/ARCHITECTURE.md](../rules/ARCHITECTURE.md), история решений — в [rules/DECISIONS.md](../rules/DECISIONS.md).

## Хранение проекта

Проекты хранятся отдельно от каталога приложения, в пользовательской папке данных. Каждый проект имеет собственный UUID-каталог:

```text
projects/
└── <project-uuid>/
    ├── project.json
    ├── assets/
    └── exports/
```

Файл `project.json` содержит версионируемую модель сайта. Текущая схема — v1: метаданные проекта, настройки сайта, страницы и ресурсы. Дерево `content.nodes` не зависит от DOM или конкретного визуального редактора.

Изменения JSON записываются через временный файл с атомарной заменой. Миграции схемы находятся в `backend/projects/migrations.py`.

## API проектов

- `GET /api/projects` — список проектов.
- `POST /api/projects` — создать проект.
- `GET /api/projects/{id}` — открыть проект.
- `PUT /api/projects/{id}` — сохранить модель.
- `DELETE /api/projects/{id}` — удалить проект.

Редактор содержимого страниц и экспортёр будут подключены отдельными этапами.
