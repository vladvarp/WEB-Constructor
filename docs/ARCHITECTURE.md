# Архитектура

Основные принципы находятся в [rules/ARCHITECTURE.md](../rules/ARCHITECTURE.md), история решений — в [rules/DECISIONS.md](../rules/DECISIONS.md).

## Хранение проекта

Проекты хранятся отдельно от каталога приложения, в пользовательской папке данных. Каждый проект имеет собственный UUID-каталог:

```text
projects/
└── <project-uuid>/
    ├── project.json
    ├── assets/
    └── exports/
```

Файл `project.json` содержит версионируемую модель сайта. Текущая схема — v2: метаданные проекта, настройки сайта, страницы, ресурсы и меню навигации. Дерево `content.nodes` состоит из узлов с `id`, `type`, `props` и `children`; оно не зависит от DOM или конкретного визуального редактора.

Изменения JSON записываются через временный файл с атомарной заменой. Миграции схемы находятся в `backend/projects/migrations.py`.

## Меню и навигация

Меню хранятся в `menus` как дерево пунктов с UUID. Внутренние ссылки указывают на UUID страницы, внешние принимают только абсолютные HTTP/HTTPS URL. Поддерживается вложенность до пяти уровней. Удаление страницы удаляет пункты, ссылающиеся на неё, вместе с их поддеревьями. Экспортёр пока не отображает меню на сайте.

API: `POST /api/projects/{id}/menus`, `PUT /api/projects/{id}/menus/{menu_id}`, `DELETE /api/projects/{id}/menus/{menu_id}`.
