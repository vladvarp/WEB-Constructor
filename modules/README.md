# Модули

Каждый модуль располагается в отдельной папке и содержит обязательный `module.json`.

Сейчас приложение обнаруживает и проверяет манифесты, но не исполняет код модулей. До динамической загрузки нужно определить разрешения, доверие, API-контракты, изоляцию, зависимости и безопасное включение/отключение.
